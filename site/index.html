How to read this

  • Score is the pass rate on the protected pages only. Pages with no protection are shown but not counted.
  • The word under a number says how the failed tries ended. challenge: the page kept showing a check or a captcha. blocked: the site refused. error: the library crashed or took too long. with click: it passed after clicking the challenge check box.
  • Controls are plain tools with no stealth. A stealth library should beat them.
  • headless means no window. headed means a real window on a virtual screen, which is harder to detect and uses more memory.
  • The trend line shows the daily score for the last 30 days. A sudden drop often means a browser update or a new protection rule broke the library.

What this does not tell you

  • Each test is one page load from one IP address with no proxy. It says nothing about thousands of requests.
  • It only loads one page. Logging in, clicking around, and other pages of the same site can be harder.
  • Sites change their protection. A target can become easier or harder without any change in the library.

This project exists to help the scraping community. It only loads public pages, a few times a day, with no login, and it keeps no page content.

Open source. The method, the list of targets and how to add a library are in the project README.
